💬 Mẫu câu (Sentence patterns)

❓ Do you like apples?
💬 Yes, I do. / No, I don't.
🇻🇳 Bạn có thích táo không? → Có. / Không.
❓ What's your favourite food?
💬 It's chicken.
🇻🇳 Món ăn yêu thích của bạn là gì? → Là thịt gà.
❓ What would you like to eat?
💬 I'd like some noodles, please.
🇻🇳 Bạn muốn ăn gì? → Mình muốn ăn mì ạ.
❓ What would you like to drink?
💬 I'd like some orange juice.
🇻🇳 Bạn muốn uống gì? → Mình muốn uống nước cam.
❓ Would you like some milk?
💬 Yes, please. / No, thanks.
🇻🇳 Bạn có muốn uống sữa không? → Có ạ. / Không, cảm ơn.
I'm hungry. / I'm thirsty.
🇻🇳 Mình đói. / Mình khát.

📐 Ngữ pháp (Grammar)

📐 some / any & would like

some + N: câu khẳng định, lời mời
any + N: câu phủ định và câu hỏi
Would you like + N? → Yes, please. / No, thank you.
I'd like (I would like) + N
  • Danh từ không đếm được (milk, water, rice) không có số nhiều, không dùng a/an.
I'd like some milk.
🇻🇳 Mình muốn một ít sữa.
There aren't any eggs.
🇻🇳 Không còn quả trứng nào.
Would you like some juice? → Yes, please.
🇻🇳 Bạn uống nước ép nhé? → Vâng, cảm ơn.
